# Processo Oficial das Sprints

Toda Sprint seguirá obrigatoriamente o fluxo:

Backlog

↓

Planejamento

↓

Arquitetura

↓

Implementação

↓

Documentação

↓

Testes

↓

Commit

↓

Push

↓

Code Review

↓

Merge

---

## Definition of Done

Uma Sprint somente será considerada concluída quando:

- Código implementado
- Documentação atualizada
- Site funcionando
- Sem erros no console
- Commit realizado
- Push realizado
- Backlog atualizado
- Changelog atualizado
- Revisão concluída
