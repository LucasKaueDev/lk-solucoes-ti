# Git Flow Oficial

main

Versão em produção.

Nunca desenvolver diretamente.

---

develop

Integração.

Recebe funcionalidades aprovadas.

---

feature/*

Desenvolvimento.

Cada Sprint ocorrerá em uma Feature Branch.

---

Fluxo

feature

↓

develop

↓

main

---

Regras

Nenhum Merge sem:

- Testes
- Documentação
- Revisão
- Commit
- Push
